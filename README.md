# Galgje

Galgje voor twee of meer spelers. Eén kiest een geheim woord, de anderen raden letters. Tien foute letters en het mannetje hangt.

- `galgje.html` is de pagina zoals hij als Claude-artifact gepubliceerd wordt (zonder eigen `<html>`/`<head>`; die worden bij publiceren toegevoegd).
- Online versie: https://claude.ai/artifact/VNSQJr4FLovmxEmxnRuS2W
- Gedeeld spel loopt via de `db`-capability van het artifact. Buiten claude.ai werkt het op één apparaat.
